# SQL Database Setup Project

This project demonstrates setting up a MySQL database, configuring user permissions,
creating tables, and inserting sample data for learning and testing purposes.

## What this project covers
- Creating databases and users
- Assigning privileges
- Designing a relational table
- Inserting and managing sample records
- Understanding data fields commonly handled in backend systems
